一、项目用途与定位

CFD（计算流体力学）长期受困于操作复杂、专业知识门槛高、学习曲线陡峭。 ChatCFD 是一个由大语言模型（LLM）驱动的智能体系统，运行在开源 CFD 框架 OpenFOAM 之上，让用户通过自然语言对话或上传论文 PDF即可完成复杂 CFD 算例的配置与运行， 实现 CFD 工作流的端到端自动化，使缺乏 CFD 专业背景的用户也能准确执行仿真。

核心价值主张

  • 自然语言 → 仿真：一句话、一篇论文即可启动 CFD 计算
  • 多模态输入：支持 PDF 论文、TXT 说明、.msh 网格文件上传
  • ChatGPT 式交互：可对话确认/修改求解器、湍流模型、边界条件
  • 结果可下载：生成完整 OpenFOAM 算例目录，可打包下载

两大使用模式

  • 模式 0（推荐）：Streamlit Web 前端，交互式上传文档+网格、对话确认配置
  • 模式 1：命令行批处理，直接指定 --document_path / --grid_path / --run_time

二、系统原理与架构

ChatCFD 采用双模型多智能体架构（DeepSeek-R1 负责推理/诊断，DeepSeek-V3 负责配置/改写）， 结合三大关键技术保证成功率与物理准确性：

① 领域结构化知识库（RAG）

  • 知识库：database_OFv24/ 预处理的 OpenFOAM v2406 官方教程数据
  • 向量化检索：论文经 sentence-transformers 编码 + FAISS 相似度搜索，精准定位物理描述段落
  • 参考案例注入：按求解器/湍流模型匹配历史案例文件作为 prompt 参考

② 迭代反思纠错机制

  • 仿真失败时捕获 stderr，交给 R1 分析根因、定位可疑文件
  • 连续同类错误 → 触发 Reflection 反思上轮失败原因，避免重复
  • 反思 2 轮仍失败 → 直接重写整个文件；最多 30 轮自修复
  • 自动处理：缺文件补建、CFL 步长控制、网格转换重试

③ 自然语言 → 案例转换

  • 解析论文中每个独立仿真算例（不同 Re/Mach/AoA/模型 = 不同案例）
  • LLM 推荐适配的 OpenFOAM 求解器与湍流模型
  • 自动抽取边界条件、初始条件、物理属性并填充到各字典文件

④ 交互多模态界面

  • Streamlit 实现类 ChatGPT 体验
  • 侧边栏：上传文档、上传网格、导出聊天记录、下载 OpenFOAM 算例 zip
  • 用户可在对话中随时修改配置（如换湍流模型）再启动仿真
